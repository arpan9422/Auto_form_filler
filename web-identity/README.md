# FormPilot — Web Identity & Product Showcase

This Next.js application serves as the **product identity, architecture visualization, and interactive showcase** for FormPilot — the AI Form Filler engine.

- **GitHub Repository**: [https://github.com/arpan9422/Auto_form_filler](https://github.com/arpan9422/Auto_form_filler)

---

## Features

- **Interactive Form Fill Simulator**: Demonstrates live state progression (`Intake → Planner → RAG Retrieval → Composer → Validator`) as fields populate in real time
- **5-Node LangGraph Agent Visualizer**: Detailed breakdown of FormPilot's stateful execution flow
- **7-Layer RAG Memory Inspector**: Interactive view of vector chunks (`PERSONAL`, `PROJECT`, `EXPERIENCE`, `EDUCATION`, `ANSWER`, `RESUME`, `EPISODIC`)
- **Full-Stack Architecture Matrix**: Comprehensive breakdown of Backend (Node, Express, Prisma, Postgres, ChromaDB), Frontend (Next.js 14, GSAP), and Extension (Chrome MV3, Vite)
- **Open Source Community Hub**: Direct links to contribute, star, and fork the main repository

---

## Getting Started

### Prerequisites

- Node.js 18+

### Running Locally

```bash
# Install dependencies
npm install

# Start Next.js development server on port 3001
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
